# MANUKURA Year 9 Pūtaiao Revision

A self-contained Year 9 Science course website covering:

1. The Nature of Science
2. Precious Wai
3. Living World
4. Space and Energy

The learning section follows the lesson sequence taught in class and includes
key knowledge, practical learning, interactive science models, videos, useful
resources and lesson completion tracking. Separate revision pages contain flip
cards, self-marking quizzes, written practice and full question banks. The
end-of-year section adds mixed practice and an exam-readiness checklist.

The official MANUKURA logo is stored as `manukura-logo.png` beside `index.html`,
so every required website file can be uploaded to GitHub in one step.

## Preview locally

Open `index.html` directly in a browser, or run a local web server from this folder.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.

## Publish with Netlify Drop

Drag the whole folder into Netlify Drop. Netlify will generate a public URL.

No build process or external database is required. The quizzes run entirely in the browser.
